# Machine Learning & Deep Learning Projects 

A collection of academic projects exploring machine learning, deep learning, neural networks, and data analysis using Python.

This repository documents my practical experience with classification algorithms, neural network architectures, hyperparameter tuning, and model evaluation.

##  Projects

### 01. Titanic Survival Prediction
**Machine Learning | Classification**

Predicting passenger survival using the Titanic dataset and comparing seven classification algorithms.

**Algorithms:**
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree (CART)
- Random Forest
- AdaBoost
- XGBoost

**Key Concepts:**
- Data preprocessing and missing value handling
- Categorical feature encoding
- 80/20 train-test splitting
- 5-fold cross-validation
- GridSearchCV for hyperparameter optimization
- ROC curves and AUC evaluation
- Model performance comparison

### 02. Fashion-MNIST Classification
**Deep Learning | Artificial Neural Networks**

Exploring neural network architectures for classifying grayscale fashion images.

**Key Concepts:**
- Fully connected neural networks
- Single and multiple hidden layers
- ReLU and Softmax activation functions
- Early stopping and regularization
- Training and validation accuracy
- Loss curve visualization
- Model comparison and overfitting analysis

### 03. KMNIST Character Classification
**Deep Learning | Image Classification**

Building and evaluating artificial neural networks for recognizing handwritten Japanese Kuzushiji characters.

**Key Concepts:**
- Image preprocessing and normalization
- Single-hidden-layer and two-hidden-layer architectures
- Epoch and batch size experimentation
- Hidden neuron configuration
- Hyperparameter tuning
- Test accuracy evaluation

## Learning Objectives

These projects focus on understanding how machine learning models learn, how architectural and hyperparameter choices affect performance, and how to evaluate model generalization.

Particular attention is given to:

- Preventing overfitting
- Understanding training and validation behavior
- Selecting appropriate activation and loss functions
- Comparing classification models
- Interpreting evaluation metrics
